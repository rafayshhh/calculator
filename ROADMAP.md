# Calculator - Open Source Roadmap

This roadmap outlines upcoming community-driven milestones for the open-source GitHub project.

---

## 🟢 Version 1.0.0 (Release Candidate)
- [x] Complete pure-Dart AST expression evaluator with trigonometry, powers, and percentages.
- [x] 65+ specialized domain tools across Science, Engineering, Math, Finance, and Everyday utilities.
- [x] 15-category Unit Converter engine.
- [x] 12-theme matrix with dynamic light/dark mode transitions.
- [x] 100% offline-first Hive binary persistence with auto-recovery.
- [x] 591 automated tests passing with clean static analysis.
- [x] Centralized `Documentation/` hub and comprehensive guides.

---

## 🟡 Version 1.1.0 (Community Polish & Web Demo)
- [ ] Publish interactive Web PWA on GitHub Pages.
- [ ] Automate multi-platform binary compilation via GitHub Actions CI/CD.
- [ ] Add extended Semantics accessibility tags across graphing canvases and keypads.
- [ ] Community issue templates and pull request checklists.

---

## 🔵 Version 1.2.0 (Ecosystem Expansion)
- [ ] Multi-language internationalization (i18n) via community contributions.
- [ ] Package distribution for Linux (Flathub, AppImage) and Windows (`winget`).
- [ ] Programmable user-defined formula storage in local Hive boxes.
- [ ] Interactive 3D multi-variable surface grapher ($z = f(x, y)$).
