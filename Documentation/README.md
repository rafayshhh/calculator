# Calculator — Documentation Hub

Welcome to the official documentation for **Calculator**, a premium, offline-first, open-source mathematical calculation engine and multi-discipline utility suite built with Flutter and Dart.

This repository is dedicated to 100% Free and Open Source Software (FOSS) published as a public GitHub project. It requires no external servers, cloud databases, user tracking, or app store telemetry.

## 🎯 Project Philosophy

1. **Zero External Dependencies for Math**: All calculations, AST evaluation, trigonometry, equation solving, and unit conversions execute via pure Dart algorithms.
2. **Offline-First & Privacy Sovereign**: 0 telemetry, 0 cloud sync, 0 external analytics. Calculation history and user preferences remain entirely on the local device via Hive binary storage.
3. **Cross-Platform Responsive**: Fluidly adapts across mobile phones (<600dp), tablets (600–899dp), and desktop/web ultrawide displays (≥900dp).
4. **Adaptive 12-Theme Design System**: 6 custom-crafted color palettes across Light and Dark brightness modes with dynamic contrast and accessible touch targets.
5. **Open Source First**: Built to be freely inspected, customized, built, and extended by developers, researchers, students, and engineers globally.
